# Instrucciones de publicación en GitHub

Nombre recomendado del repositorio:

```text
biosacha-backend-aplicaciones-moviles
```

Descripción recomendada:

```text
Backend del proyecto móvil BioSacha: JWT, CRUD, caché cache-aside, corrección N+1 y worker asíncrono.
```

Configuración recomendada:

- Visibilidad: pública, salvo disposición diferente del docente.
- Rama principal: `main`.
- No añadir otro README desde GitHub, porque este proyecto ya lo incluye.
- No subir nunca el archivo `.env`.

Después de crear el repositorio vacío, use en la Terminal los comandos que se proporcionarán durante el acompañamiento.
